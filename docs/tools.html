ESP-beatsy · Offline utilities

Audio Tools

Small browser-based utilities for audio files created or used by ESP-beatsy. The files are processed locally; this page does not upload them.

← Audio System Design ToolTool notes

These tools are designed as a home for additional project utilities in the future.

1. Repair recorder .tmp file

Recover a WAV file left unfinished by AudioRecordFile, for example after a reset or power loss.

The source file is not modified. The tool downloads a repaired .wav file that you can copy back to the SD card or LittleFS after checking it.

The tool uses the recorder's 44-byte, 16-bit PCM WAV header. It recalculates the RIFF and data-chunk sizes from the file length and drops any incomplete final mono sample or stereo frame.

2. WAV to Sketch

Convert a PCM WAV into a constant packed sample table for AudioPlayMemory.

Supports mono and stereo, 16-bit integer PCM WAV files. Stereo output is stored as interleaved left/right sample pairs and uses both AudioPlayMemory outputs; a mono source is duplicated to left and right. When the output rate differs from the source, conversion uses an 80-tap, 512-phase windowed-sinc FIR resampler with anti-alias filtering for downsampling.

Play previews the converted PCM data exactly as it is stored in the generated sample table.

Include the header in one sketch source file, then call player.play(AudioSampleYourName);. For stereo output, connect AudioPlayMemory output 0 to the left destination and output 1 to the right destination. The table format is for AudioPlayMemory, not the filesystem-based AudioPlaySdWav.

To keep browser memory usage reasonable and match the table format, output is limited to 100 seconds and the 24-bit sample-count limit of AudioPlayMemory.

3. MIDI to ESP-beatsy player (MIDITONES V2.0)

Convert a MIDI file into the ESP-beatsy MIDITONES V2.0 byte stream, supporting up to 32 voices.

Advanced MIDITONES options

The channel mask uses bit 0 for MIDI channel 1, bit 1 for channel 2, and so on. For example, 3 selects channels 1 and 2. Binary and parse-only modes do not produce a C source file.

Binary Playtune byte stream. Download the generated .bin file below.
Parse-only mode completed. No score output was generated.

The C output uses the ESP-beatsy MIDITONES V2.0 format: score[], PROGMEM, 5-bit voice IDs (up to 32 voices) and end-of-score command 0xC1. It is not byte-compatible with upstream MIDITONES V1.9.

Defaults: six tone generators, all 16 MIDI channels, balanced track scheduling, no velocity bytes, zero key shift and C source output. Select 1–32 voices. MIDI parsing and conversion run locally in the browser; the file is not uploaded.

4. SF2 SoundFont to AudioSynthWavetable

Load a SoundFont, audition its presets and generate an instrument header for the current AudioSynthWavetable API.

The file is parsed locally in your browser. It is not uploaded.
